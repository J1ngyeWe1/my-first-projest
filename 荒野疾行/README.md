# 荒野疾行 | 恐龙跑酷

一款纯前端单页恐龙跑酷游戏，原生 HTML / CSS / JS + Canvas 2D 实现，无框架、无外部依赖。

## 玩法

- **Space / ↑** 跳跃，**↓** 下蹲，**F** 飞行，**G** 双倍金币
- 三种障碍：仙人掌（跳过）、矮栏杆（跳/蹲都能过）、高栏杆挡板（只能下蹲钻过）
- 收集金币、升级商店、排行榜、本地存档

## 本地运行

```bash
python -m http.server 8000
# 或双击 star_game.bat
```

浏览器打开 `http://localhost:8000/index.html` 即可。
